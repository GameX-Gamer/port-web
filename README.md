## How i made it
The website started as its a simple idea, i can do it in some time, to thousands of line of code.
I wanted to push myself further so rather than making a simple page i experimented with animations,
positioning, scrolling, transitions and making the different sections feel connected.
I created the 3d visuals in blender and integrated them into the website through canvas.

## features
• Interactive portfolio layout<br>
• Animated sections<br>
• 3D visuals created with Blender<br>
• Scroll-based animations<br>
• Libraries like gsap and lenis integrated<br>
• Modern typography and visual design<br>

## How to run it
### Method 1: Direct File Access
1. Clone the repository:
   ```bash
   git clone [https://github.com/GameX-Gamer/port-web.git](https://github.com/GameX-Gamer/port-web.git)
2. Navigate into project folder port-web.
3. Double-click index.html (or right-click index.html → Open With → choose your browser)
### Method 2: VS Code Live Server
1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension (by Ritwick Dey) from the Extensions marketplace (Ctrl+Shift+X / Cmd+Shift+X).
3. Right-click index.html in the file explorer and select Open with Live Server.
4. The site will launch automatically at http://127.0.0.1:5500/

## How it Works
I used Html, Css rather than using heavy frame works because of its simplicity and benefits like -instant load speed, -easy hosting,
this website is partially responsive as i didnt got time to finish it completely, i used flex-box, flex-grids values like rem and vh for easy responsiveness
I used gsap and lenis and integrated smoothScroll so i could load my render more interactively.
However there was a trade-off i had to sacrifice crisp 4k images for fast-loading.
